### 👋 About me

I'm a Police Communication Officer at **Punjab Safe Cities Authority (PSCA)** in Lahore — real-time emergency communication, surveillance operations, and critical incident response. Outside the control room, I do defensive security: I write detection templates and rules for open-source projects, validate every one of them in my own lab before I submit it, and I'm building toward IAM and cloud security.

**Direction:** Defensive security → Identity & Access Management → Cloud security
